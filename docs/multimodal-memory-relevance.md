# 多模态记忆与当前研究的关系

2026-09-05 完成轻量对照后的决策：**作为后续扩展**。目前工程重点仍是预算下的记忆保留、整合与效用；尚没有真实多模态长期任务的收益证据。该判断基于现有任务与工程边界，可在新证据出现后调整。

| 候选方向 | 任务价值 | 工程与评测成本 | 当前安排 |
|---|---|---|---|
| GUI / 网页截图 episodic memory | 回查操作时所见状态、控件位置与错误提示 | 截图重复、动态状态与时间有效性；需操作轨迹和可核验答案 | 后续扩展，先收集少量可标注轨迹 |
| 图表 / 幻灯片 / 论文 document memory | 回查文本摘要无法完整表达的图表和布局 | 已有页面检索模型可复用；需页码、区域引用与视觉问答评分 | 最适合先做轻量验证；本次 demo 覆盖这一类 |
| 视频关键帧 + 摘要 event memory | 回查事件过程、顺序和变化 | 关键帧选择、时间对齐、存储预算与跨帧评分成本较高 | 更晚考虑 |

与申请方向的相关性：可以展示对多模态知识增强、证据利用与研究边界的理解；完整训练栈和大规模视频系统不是当前项目主线的必要交付。

## 如何使用第三阶段成果

依据 [memory-utility-note.md](memory-utility-note.md) 的补充控制，全量 top-5 召回 100% 但答案 EM 为 94.4%。因此后续视觉扩展必须分别测量页面/证据召回、答案得分和证据引用正确率；不能把“找到了图片”当成“记忆有效”。当前文字实验的错误率不能迁移解释视觉模型。

第三阶段还提示保留主体、来源与时间状态的重要性。候选设计是让原始截图或页面保有稳定 ID、时间戳和源位置，以结构化摘要作为入口，同时允许回查原图。它仍是假设，不代表已经证明双份保留最优，也未修改现有记忆 schema 或保留策略。

## 什么证据足以考虑纳入主线

已补齐当前 demo 的真实 OCR 对照。下一步选取新页面和明确依赖视觉信息的任务，在固定预算下比较原图、摘要、二者结合。继承第三阶段的无记忆/相关/无关/冲突/整合五条件，预先冻结评分协议，同时报告存储与上下文成本。只有出现可复查的下游收益，并且成本可接受，才考虑正式纳入主线。

当前限制：8 页和 5 个手选问题仅用于探索检索行为；未运行视觉生成或长期截图记忆实验。

## 本机三路证据与阶段验收

已使用 Tesseract 5.5.0 从同一批页面 PNG 做真实 OCR，对比 VisRAG-Ret 与两条 MiniCPM 文本路径。指定页排第一的数量为视觉 5/5、原生文本 4/5、OCR 3/5；所有指定页均进入前三。原生文本和 OCR 分别编码为 26/24 块，原本超长页面已完整覆盖，120 个页级分数与排名重算通过。

q1 的原生文本从旧整页方法的第一位变为分块后的第二位，说明预处理本身会影响排名。q2 的 OCR 图表文字存在可回查的失真，同时目标排名下降；这提示解析路径值得对照，但不能隔离为唯一原因。q3/q5 在部分视觉内容识别不完整时仍可定位页面，因此检索成功不能证明证据被完整利用。

基于这些结果，仍选择“作为后续扩展”：保留原图的任务价值有合理动机，但尚无下游收益与成本评测支撑纳入主线。原计划的论文笔记、本机检索、真实 OCR 对比与方向判断已完成；PP-OCRv3、官方新数据子集与视觉生成效用属于后续增强。参见 [完整观察](../experiments/multimodal-retrieval-mini/results/v0.1/observations.md)。
