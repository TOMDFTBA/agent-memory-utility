# Memory Utility：检索命中与任务收益之间的差异

> 已完成输出协议与时间措辞的补充控制，见文末与[补充结果](../experiments/memory-utility/controls/results/v0.1-test/report.md)。下文第一版结果保留原始口径。

## 研究问题与实验边界

第三阶段在第二阶段的冻结检索记录上研究：记忆已被检索到时，是否改善短答案任务；保留或整合策略如何影响这种收益。效用定义为 U(m,q)=EM(q|m)−EM(q|空)。它是相对无记忆基线的任务表现差值，不是单条记忆在任意上下文中的固有效用，也不能直接测量模型内部推理过程。

本阶段借鉴 RAG-DDR 的下游效用问题意识，没有复现其训练或声称论文复现。使用本机已有 MiniCPM-2B-SFT，通过冻结的纯文本提示执行确定性解码，最多生成 24 tokens。未依据这批结果调整提示、模型或主评分规则。数据、提示、原始回答、证据 ID、配置和输入来源散列全部保存。

## 数据、对照与评分

从第二阶段 balanced-10000 场景的三个种子 11/22/33 中，各选全部 18 个测试主题的第一条查询，共 54 个问题。没有使用按成败筛选的 10 个诊断样本，也不将同主题四种改写重复计数。三个种子仍共享 18 个主体/关系模板，所以 54 不是独立主题数量。开发/测试主体沿用第二阶段隔离。

每个问题有五个控制条件：无记忆、当前正确事实、其他主体无关事实、新旧冲突事实、规则整合后的事实。冲突条件明确标注 Currently/Previously，新旧顺序交替。整合操作只读取记忆，按主体/关系与时间戳选择最新版本，保留来源 ID，去掉 Currently 前缀。它保留事实值，但改变了时间措辞；不是学习式摘要，也不是单纯长度匹配实验。

另外回放全量保留与 50% 语义去重策略各自的 top-1/3/5，保持第二阶段排名。总计 54×11=594 次生成。检索命中采用 canonical_id，目标是否仍在库由索引映射判断。主指标是规范化短答案 Exact Match，辅以 token F1；只包含正确答案词的长输出不自动判对。报告生成模型 tokenizer 计算的记忆 token 数，不把它当作完整服务成本。

## 主要结果

| 控制条件 | Exact Match | 相对无记忆效用 | 平均记忆 tokens |
|---|---:|---:|---:|
| 无记忆 | 0.0% | 0.0 个百分点 | 0.0 |
| 相关记忆 | 100.0% | +100.0 个百分点 | 11.7 |
| 无关记忆 | 24.1% | +24.1 个百分点 | 13.6 |
| 新旧冲突记忆 | 100.0% | +100.0 个百分点 | 24.9 |
| 规则整合记忆 | 35.2% | +35.2 个百分点 | 9.7 |

无关记忆的正分不说明模型正确使用了目标主体的证据：合成任务答案空间仅每关系四个值，不同主体可能恰好共享答案。该现象提示，答案正确和证据归属正确是不同的指标；后续需要扩大答案空间并评测引用。无记忆全部答错使本实验不可能出现相对此基线的负效用，不应把相对相关条件下降误称为 U<0。

| 检索条件 | Recall@k | Exact Match | 命中但答错 |
|---|---:|---:|---:|
| 全量 top-1 | 63.0% | 63.0% | 0/54 |
| 全量 top-3 | 100.0% | 88.9% | 6/54 |
| 全量 top-5 | 100.0% | 94.4% | 3/54 |
| 50% 去重 top-1 | 29.6% | 29.6% | 0/54 |
| 50% 去重 top-3 | 51.9% | 59.3% | 3/54 |
| 50% 去重 top-5 | 51.9% | 57.4% | 4/54 |

在这个子集，全量 top-5 的 3 个错误均为错误事实值，不是额外解释导致的格式误判。50% 去重已移除 26/54 个目标；增加 k 无法找回已删除事实。部分未命中问题仍猜中答案，因此答案准确率可能高于目标召回率，二者不能互相替代。

## 整合与输出格式的混杂因素

模型有时答对第一行，然后续写不存在的问答。主评分坚持原始规则。观察到这一现象后，额外做首行 EM 诊断：固定取第一个换行之前的文本，不搜索标准答案。该分析为事后探索，不替换主指标。

整合条件首行 EM 为 70.4%，高于严格 EM 的 35.2%；全量 top-3 从 88.9% 提升至首行 EM 100%。这说明前者部分退化、后者全部严格评分错误与续写有关。整合条件仍有 16/54 的首行错误，不能只用终止生成规则解释。相关条件和整合条件的当前事实值一致、主要差别为 Currently 前缀，结果支持“时间措辞可能影响此模型的行为”的后续检验，但没有证明压缩普遍有害。

## 五个可复查案例

1. **正效用**：seed 11、Person001 城市，无记忆输出 UNKNOWN；给出当前事实后回答 Perth，U=+1。
2. **格式退化**：同一问题的整合事实仍为 Perth；模型先答 Perth，再续写法国首都问答。严格 EM=0，首行 EM=1，不能标为事实被压坏。
3. **检索命中但输出不合规**：同一问题全量 top-3 提供正确事实，模型回答 Perth 后继续问答；这是行为错误，不是未检索到。
4. **正确事实未进 top-1**：同一问题在 50% 去重 top-1 仅提供旧事实 Kyoto，输出 Kyoto 后续写。应先检查保留与排名，不能责怪生成器忽略不存在的正确证据。
5. **正确事实在首位但答错值**：seed 22、Person005 当前项目为 Delta，全量 top-5 第一条即为正确事实；其他主体多条项目为 Atlas，模型最终回答 Atlas。单条相关记忆条件答对，说明这组额外上下文伴随了任务退化。

原始提示和完整证据见 `experiments/memory-utility/results/v0.1/responses.jsonl`；机器可读代表案例见同目录 `cases.json`。

## 对保留策略的初步假设

应先保证目标主体的最新有效事实被保留，再减少相似主体干扰，同时保留清晰的当前/历史状态。候选假设是：在相同存储和上下文预算下，“按主体/关系整合并保留明确时间状态”的策略可能比仅依靠相似度去重更能保持答案收益。

下一次验证应冻结新主体、新答案值的测试集，并比较保持 Currently 的整合、去掉前缀的整合及长度匹配对照；同时采用模型适配的对话模板与预先确定的输出结束协议。增加证据引用检查，区分碰巧答对与正确主体证据支持。以上是待验证方向，本次没有训练效用预测器，也未将候选策略部署回记忆库。

## 验证与限制

594 条配对输出已通过完整性、唯一性、数据散列、提示、证据 ID、标准答案、评分重算与检索标签核验。主报告另有种子间 SD，但不报告虚假的独立样本显著性。代码测试包含规范化评分的否定/多答案误判、时间整合顺序、条件命中一致性以及损坏输出拒绝。

实验只覆盖英文合成事实、单模型、单一时间均衡场景、显式时态冲突与一种规则整合。没有独立固定 token 预算试验、真实长会话、学习式摘要、引用评分或多模型验证。规则整合保留关键事实已验证，未观测到整合算法损坏事实的案例；该错误类别不能人为补造。完整报告为描述性证据，不应推广为普遍性能保证。


## 补充控制：区分输出格式与时间措辞

已在 seed 77 的六个开发主题上，比较 plain/chat 提示与 EOS/首行结束的四种组合，共 144 次回答。按开发集平均 EM 冻结 plain_line（63.9%，原 plain_eos 为 58.3%；两个 chat 版本均为 55.6%）。未根据测试结果继续调整协议。随后对原 54 个问题运行六个控制条件及六个检索条件，共 648 次真实模型回答。

| 检查 | 第一版 | 补充控制 |
|---|---:|---:|
| 删除 Currently 的整合 EM | 35.2% | 70.4% |
| 保留 Currently 的整合 EM | 对应 Relevant：100.0% | 100.0% |
| 全量 top-3 EM | 88.9% | 100.0% |
| 全量 top-5 EM | 94.4% | 94.4% |

固定首行输出后，整合版本有 19/54 个问题不再因为续写丢分。保留前缀相对删除前缀再改善 16/54 个问题，恶化 0 个；例如 Person002 的当前编程语言，保留前缀答 Rust，删除前缀答 UNKNOWN。两种整合的选中事实和来源相同，仅正文前缀不同。保留前缀的正文与 Relevant 完全相同，54 对生成结果全部一致。

这轮控制将第一版观察收窄为两项可复查因素：输出续写造成严格 EM 丢分，删除具体时间措辞也影响该模型回答。这不是整合算法损坏事实，也不能归因于所有摘要或压缩方式。前缀同时增加 token，尚未将语义与纯长度完全分开。

全量 top-3 的六个原始错误由结束协议解决，但 top-5 仍有三个错误事实值，尽管 Recall@5=100%。因此“检索命中不保证答对”的主要证据仍成立；在本数据子集，更多上下文还可能引入干扰。应优先保留正确主体的最新事实与清晰时间状态，再评测增加上下文的收益。

本轮属于对已观察测试集的后续诊断，不能称新盲测；协议选择只使用独立开发主体，但开发集规模很小。原有单模型、合成答案碰撞、18 个主题跨种子重复与未评测引用等限制继续适用。未训练模型、未自动修改保留策略。

补充数据、源码、冻结选择、原始 token 与终止原因均已保存；144 条开发输出和 648 条评测输出通过核验，完整项目 37 项测试通过。原 594 条回答、原始源码与图表均保留。至此，本阶段原计划及两项优先补充均完成；独立新测试集、引用评分和多模型验证作为后续扩展。
