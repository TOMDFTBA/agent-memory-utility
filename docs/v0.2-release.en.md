# v0.2: release and reproduction

English | [简体中文](v0.2-release.md)

This release packages the four-stage experiments as inspectable code, browsable reports, and a complete evidence archive. The software version is 0.2.0. The release history separates the v0.1 DeepNote supplement, v0.2 E1–E4 experiments, and PilotDeck closing study.

## Findings and scope

In E3, utility_aware exceeded frozen importance by 0.2014 EM averaged over three primary budgets, with a descriptive 95% interval of [0.0972, 0.3056]. E4 shows that redundant evidence can leave the LOO objective unable to distinguish useful sets. Exact predicted-score selection did not improve average EM here.

These results concern a fixed MiniCPM system and four equally weighted synthetic stress scenarios, with four memories and two future tasks per trajectory. They do not establish natural-user generalization, online long-term benefit, or graph-method effectiveness. See [E3](../releases/v0.2.0/reports/e3-formal-model/report.md) and [E4](../releases/v0.2.0/reports/e4-diagnostic-model/report.md).

## Publication boundary

| Content | Treatment |
|---|---|
| Active code, protocols, configurations, datasets, tests | Regular version control |
| Public manifests, reports, audits, summaries, figures | releases/v0.2.0/reports; enumerated in published-artifacts.json |
| Complete responses, predecessor inputs, historical source snapshots | One frozen-experiments.tar.gz; per-file checksums in frozen-index.json |
| Local results and repeated snapshots | Restored locally, ignored by Git; existing local evidence is not deleted |
| Weights, indexes, caches | Excluded |

The archive is about 1.7 MB and preserves 412 original files. Pilot and development evidence remains available for provenance and dependencies, without being presented as primary findings. v0.1 frozen results and exclusions remain unchanged.

## Clean-checkout verification

Install dependencies using the [usage guide](usage.en.md), then run from the repository root without models or a GPU. Study verification requires the historical commit described in that guide:

```bash
python scripts/release_artifacts.py verify
python scripts/release_artifacts.py restore-results
python scripts/audit_v02.py
python experiments/utility-retention/audits/verify_e4.py experiments/utility-retention/results/e4-diagnostic-model
PYTHONPATH=src python studies/verify.py
python -m pytest -q
python -m ruff check src tests scripts integrations experiments/utility-retention studies --exclude '**/results/**'
```

Restoration preflights all files and rejects conflicting content or escaping paths. The audit recomputes labels, predictions, selections, scores, paired statistics, and set diagnostics. It neither regenerates answers nor presents historical GPU replay as new inference.

## Historical sources and release compatibility

Original manifests, source snapshots, responses, and derived files remain byte-identical. source-compatibility.json connects reviewed relocation, shared scoring, backend aliases, and the diagnostic adapter to hashes of the complete current implementation. Unregistered changes fail. Compatibility does not mean byte-identical source.

Exact historical execution is also available in isolation:

```bash
python scripts/release_artifacts.py restore --output /tmp/utility-frozen-e1 --source-run e1-extension-model
PYTHONPATH=/tmp/utility-frozen-e1/src .venv/bin/python /tmp/utility-frozen-e1/experiments/utility-retention/evaluate.py /tmp/utility-frozen-e1/experiments/utility-retention/results/e1-extension-model
```

source-run selects the source variant recorded by that run. The original runner for the two early pilots was not fully preserved: their saved scores and labels remain verifiable, but exact source restoration is not claimed. No such gap was found for frozen E1 or subsequent primary experiments.

The E1 extension verifier now uses shared model configuration and separates CPU checks from tokenizer replay:

```bash
python experiments/utility-retention/audits/verify_run.py experiments/utility-retention/results/e1-extension-model
python experiments/utility-retention/audits/verify_run.py experiments/utility-retention/results/e1-extension-model --verify-tokens --model-config configs/local.yaml
```

The second command requires identity-matching local models. This release cleanup did not rerun the model path.

## Implementation compatibility

- E1 construction, validation, reporting, and diagnosis share the `utility_retention` package; top-level CLIs remain compatible. Stages reuse common I/O, model backends, selectors, prediction, and response validation while retaining separate lifecycles.
- New deletion plans use `intervention`; read-only adapters preserve frozen `candidate` records. Backends accept hyphenated and underscored aliases. Shared `longmem.scoring` is checked against the unchanged v0.1 scorer on 600 archived answers.
- Software and manifest-envelope versions evolve separately. Cross-version baseline variants, budget units, and retrieval implementations follow explicit [release contracts](../releases/v0.2.0/release-contracts.json).
