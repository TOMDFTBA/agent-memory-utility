# E2结果解释与交接

本轮已完成真实模型验证开发及独立审计。主模型full-a10已冻结；260次去重推理，累计逐题177.4秒。E3正式测试尚未运行。

- 25%/50%/75%存储预算的主模型EM为0.417/0.500/0.875，recency为0.083/0.208/0.417，retrieval_frequency为0/0.292/0.583。50%预算的配对差异区间跨零。全部数值来自模型选择使用的12条验证轨迹，仅为开发信号。
- 去frequency消融在50%预算达到0.667，其中frequent_but_useless从0提升到0.667；不事后将消融赢家替换为主方法。频次是否有害需要新数据验证。
- 主模型MSE优于零预测，MAE反而更差。零预测选择空集后EM为0；不能仅用回归误差判断保留策略。
- 75%预算主模型EM高于full参照0.792；完整存储并非性能上界。这并不证明一般压缩收益，更不能从验证集推断自然任务表现。
- 75%预算hindsight LOO的冗余场景EM为0.333，预测主模型为1；hindsight整体有1/3快照选择空集。真实单条标签也可能形成差的集合决策。尚未执行E4枚举，不能完整归因。
- history_observed在当前训练集中为常数；训练负标签只有2条。当前数据不足以可靠评估缺失历史或负贡献识别。

交接frozen-predictor.json中的model对象给utility_retention.prediction.predict；输入必须是六项白名单历史特征字典列表。不要重新拟合预处理；按相同token预算选择器跳过非正分数。模型和参数身份、原始验证回答摘要均在冻结产物中。

本轮是六特征最小E2实现。importance/provenance特征以及importance/semantic_dedup基线需在E3正式测试前明确取舍并冻结。更改模型、prompt、retriever或评分需要重新生成对应版本标签。后续新方法需要新盲测证据；保留当前结果与全部负结果。
