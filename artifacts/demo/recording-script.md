# 2–3 分钟演示录屏脚本

预先完成环境安装；终端位于项目根目录。使用合成事实，不使用个人资料。

1. **0:00–0:20：目标。** 展示 `docs/architecture.md`：长期记忆可以跨进程保存、被检索，并作为回答证据。
2. **0:20–1:10：执行。** 运行 `.venv/bin/python scripts/demo.py --mode model`。
   说明 `01-write` 使用 MCP 写入 Alice 的编辑器偏好和一条干扰事实；写入进程结束。
3. **1:10–1:40：第二轮。** 展示 `02-build`、`03-pipeline` 和 `04-verify`：UltraRAG 启动新的 MCP 服务，检索旧事实，真实模型回答后回写。
4. **1:40–2:10：证据。** 打开 `artifacts/demo/latest-model.json`，展示 `alice-editor`、原始证据、相似度、生成回答及回写记录的 evidence_ids。指出 generated 记录未被用户确认。
5. **2:10–2:40：可靠性。** 执行 `.venv/bin/python -m pytest -q`，说明涵盖日志重放、索引丢失、重复写入、新旧事实替代。
6. **2:40–3:00：边界。** 当前是第一阶段最小系统；后续测量规模、压缩和记忆效用。不要把 test 模式的固定证据输出表述为真实模型推理。

模型耗时与硬件有关；可剪去加载等待时间，保留命令和未剪辑审计文件。
