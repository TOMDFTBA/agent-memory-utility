# E2 development v1 — frozen before validation inference

Scope: train signed future-value predictors on E1 extension training handoff (24 trajectories, 96 memory labels), select on its validation split (12 trajectories, 48 labels), freeze for E3. No test labels, test features, or test task evaluation in this run. Existing E1 test summaries have already been disclosed; this is development, not new blind-test evidence. E1 output is read-only.

Features: recency_rank (0 newest), age (decision order minus event order), retrieval_frequency (actual past retrieved count), history_observed (any past opportunity), historical_similarity (maximum past query embedding similarity while memory existed), memory_tokens (E1 tokenizer cost of JSON memory_id/content serialization). Exactly this whitelist enters inference; IDs join records only. Missing similarity uses the training median, or 0 if all missing; history_observed distinguishes no observation from observed zero retrieval. Population standardization and imputation are fit on train only; constant feature scale is 1. No conflict, template, scenario, support IDs, answers, or future-query features. Importance scoring and provenance are deferred to separately frozen E3 development; this is an explicit reduced-feature E2 implementation.

Models: zero baseline and ridge with unpenalized intercept, objective sum squared errors + alpha times squared coefficients; alpha in [0.1, 1, 10]. Four groups: full six features, no frequency, no recency (drop both age/rank), recency plus frequency only. Retain signed outputs without clipping. Uncertain training labels cause explicit failure rather than silent conversion. No resampling, ranking model, MLP, LLM scorer, or test refitting. Training-row order is the frozen handoff order.

Selection: maximize validation trajectory-mean downstream EM averaged equally over 25%, 50%, 75% budgets, separately per feature group. Ties: lower validation MAE, then larger alpha, then candidate ID. Main model remains the full-feature group winner; ablations are reported separately. Zero predictor is a baseline, not an alternative group winner. Strongest heuristic chosen between recency and retrieval_frequency with the same mean EM and lexical tie-break. Random uses three frozen seeds and averages within trajectory before cross-trajectory aggregation.

Budgets: floor(ratio * sum of individual serialized memory token costs), ratios 10%, 25%, 50%, 75%. 10% cannot fit a memory in all 36 development snapshots (checked before prediction), so retain as degenerate reference and exclude from model selection. Descending score; ID ties; skip records that do not fit. Predicted and hindsight LOO skip scores <=0 and may leave budget unused. Selected IDs are sorted before retrieval to keep storage representation canonical. Hindsight uses validation labels only and is a diagnostic, never a fitted feature. Full is exempt from storage limit; no_memory is empty. No importance/semantic_dedup comparison or Stage 3 completion claim in this reduced development run.

System: E1 extension MiniCPM embedding/generation files and settings, unchanged engine source, prompt, tokenizer, exact-match/token-F1 normalization, read_budget=1024 and top_k=3. One deterministic generation seed (20260912); E1's three deterministic repeats were identical, so repeated identical runs are not new evidence. No online writes, reselection or frequency update. All candidate subsets are saved before the evaluator reads validation future queries. Predictor/selector never receive task snapshots, labels (except explicitly separate hindsight scores), or diagnostic metadata.

Cost: at most 1000 unique snapshot/subset/query/seed generations and 3600 cumulative generation/retrieval seconds, excluding model hashing/loading. Identical conditions across candidates reuse a single durable response within this output only; all inputs/config/model/source hashes belong to the enclosing manifest. No unverified E1 response reuse. Resume checks all identity fields, raw keys and scores; incomplete/missing runs fail, never become zero. Preserve source snapshots, protocol/config/train/validation inputs and validation task snapshots. Freeze final predictor after validation, with hashes tying it to models and results; no train+validation refit.

Metrics: snapshot Spearman with average tie ranks (undefined if true/predicted ranks constant), MAE/MSE, negative prediction counts/precision/recall (undefined denominator -> null), positive-memory coverage under budget (undefined if no positive label), per-trajectory EM/F1, actual store/read tokens, empty subset rate, and scenario breakdown. Paired 5000-resample trajectory bootstrap intervals; model-selection intervals remain descriptive and optimistic, not confirmatory. Each trajectory, not each memory/query/repeat, is an independent reporting unit. Pressure scenarios are equally sampled and do not represent natural distribution. Complementarity is limited by generator behavior; redundancy can invalidate additive LOO retention. Negative-label counts are too small for robust harmful-memory claims.

Completion: all planned validation conditions verified, all models/selection records/predictions audited, frozen full-feature model and ablation/heuristic choices exported, original E1 files untouched. No claim of E3 formal test or E4 enumeration completion. Changed system or revised protocol requires new output/version.
