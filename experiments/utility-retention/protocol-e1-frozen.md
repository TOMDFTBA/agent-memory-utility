# E1 合成压力集测量协议（2026-09-12，运行前冻结）

本协议继承 protocol.md 的 schema、评分、历史边界、隔离删除、上下文抽样、失败处理与解释限制；本文件明确本次实验的规模和运行决策。它冻结 E1 测量，不宣称冻结 E2–E4。

依据已完成 model pilot：144 条运行累计逐题耗时 60.4 秒，中位数 0.418 秒；18 个标签中 12 正、6 零，重复标准差为零；完整记忆与空记忆开发差异为 1。pilot 仅用于成本和流程开发，其事实不复用于本数据。

## 冻结设置

- 数据：generate_e1_dataset.py，seed=2026091202。12 条独立用户轨迹；train、validation、test 各 4 条，每个 split 各包含四种场景一次。按用户分配 split 后生成独立事实与实体。
- 每轨迹 1 个快照、4 条 memory、H=2 个连续未来任务、3 个重复 seed（20260912、20260913、20260914）。同一轨迹两题为相同事实的两种问法，不作为独立统计样本。
- old_but_useful：未来所需 access code 位于最早事件；其余后续记录无助于未来答案。
- frequent_but_useless：历史连续三次询问 service desk reference，未来只问 access code。历史检索次数由真实 retriever 计算，运行后核查无用条目至少被检索三次；不要求其他条目频次更低。
- redundancy：两条独立物理记录提供等价 access code，canonical_id 相同，支持集合用 OR 表示。
- complementarity：两条记录分别提供六位 code 的前后三位，答案需要拼接，支持集合包含两条；单条记录不含完整答案。
- 全集为人为压力样本，四场景各 25%；没有自然任务分布样本，禁止将均分解释为自然用户表现。
- 系统：configs/local.yaml 中 MiniCPM-Embedding + MiniCPM-2B-SFT，实际文件摘要、模型配置及 runtime 由 manifest 固定；GPU；确定性生成；统一 top_k=3、B_read=1024。完整存储有 4 条，故可观察删除后的第四位补位。
- 阈值维持 pilot 前预设值，见 configs/e1-frozen.json。仅使用 train/validation 检查 memory 依赖 >=0.1、三次重复标签标准差 <=0.05、符号一致率=1。test 仅最后评估，不据其结果改 prompt、评分或参数。
- 预计 504–576 条生成（context 抽样层的非空情况决定）；总生成次数上限 576；累计逐题计算预算 1800 秒。若超限，保存不完整结果，不作为完整正式运行。
- 汇总按轨迹平均；full−no_memory 配对差异用固定 seed=20260912、5000 次轨迹 bootstrap 给出描述性 95% 区间。单独报告 split、场景及正零负/不确定标签数量。
- 负标签不是完成条件；若未观察到负值，明确报告零个，不人为构造或修改结果。

## 验收和边界

保留完整原始输出；独立重算标签和评分，核查存储隔离、所有候选覆盖、读取预算、上下文不补位及历史特征无未来输入。测量门槛失败就记录负结果，不启动预测器训练。

此规模只支持有限合成压力场景中的测量与诊断；不能证明真实世界泛化、预测器可学习、任意规模稳定性或非加性机理。冗余与互补在此为 E1 标签案例，不替代 Stage 4 成对子集枚举。正式 predictor 的超参不能根据这些测试标签调节。
